# Istanbul_Car_Park_Availability_API

A data visualization study using Python to show live availability of car parks in Istanbul. IMM Open Data Portal is the data source.

Data Source: https://data.ibb.gov.tr/en/dataset/ispark-otopark-detay-bilgileri-web-servisi

License of Data Source: https://data.ibb.gov.tr/en/license

Streamlit library of Python is used for user interface
